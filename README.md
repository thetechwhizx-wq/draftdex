# DraftDex — Pokémon Auction Draft & Battle

A mobile-first Pokémon draft auction, scouting, and battle web app built with vanilla JS, Tailwind CSS, and PeerJS for P2P multiplayer.

## Play

1. Open the hosted URL
2. Tap **New Match** → **Create** to start a solo match vs DexBot
3. Share your room code with a friend to play P2P multiplayer

## Local Development

```bash
node server.js
# Open http://localhost:3000
```

## Deploy to Render

1. Push this repo to GitHub
2. Go to [render.com](https://render.com) → New → **Static Site**
3. Connect your GitHub repo
4. Set **Publish Directory** to `.` (root)
5. Leave Build Command empty
6. Deploy
